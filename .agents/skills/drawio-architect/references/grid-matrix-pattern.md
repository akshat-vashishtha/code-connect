# The Grid-Matrix Pattern for Professional Draw.io Diagrams

The Grid-Matrix Pattern is a systematic layout design designed specifically for AI-generated architecture diagrams. It prevents the typical "spaghetti" layout generated by unconstrained models.

---

## 1. Spatial Math & Grid System

All nodes MUST be positioned using discrete mathematical intervals. Never let a model approximate or guess coordinates.

### Standard Container Metrics
* **Standard Node Width ($W$):** 240px (or 260px for long descriptions)
* **Standard Node Height ($H$):** 110px
* **Horizontal Gutter ($G_x$):** 80px
* **Vertical Gutter ($G_y$):** 120px

### Coordinate Calculation Formula
Given column index $c \in \{0, 1, 2, \dots\}$ and row index $r \in \{0, 1, 2, \dots\}$:
$$\text{col\_start}(c) = \text{offset}_x + c \times (W + G_x)$$
$$\text{row\_start}(r) = \text{offset}_y + r \times (H + G_y)$$

### Standard Tier Layout (Top-to-Bottom Flow)
1. **Row 0 ($y \approx 80$): Ingress & Clients**
   - User Browser, Mobile Client, API Gateway, Edge Auth
2. **Row 1 ($y \approx 300$): Domain Services Layer**
   - Microservices arranged horizontally side-by-side
3. **Row 2 ($y \approx 520$): Asynchronous Backbone & Workers**
   - Message brokers (Kafka/RabbitMQ), Worker Pods, Sandboxes
4. **Row 3 ($y \approx 740$): Persistence & State Stores**
   - Primary SQL/NoSQL databases, persistent object stores

## 3. Orthogonal Connector Routing Rules

Every connector arrow MUST follow these three non-negotiables:

1. **Always use Orthogonal Style:**
   `edgeStyle=orthogonalEdgeStyle;rounded=1;orthogonalLoop=1;jettySize=auto;html=1;`
2. **Explicit Anchor Points:**
   - **Horizontal (Left to Right):**
     `exitX=1;exitY=0.5;exitDx=0;exitDy=0;entryX=0;entryY=0.5;entryDx=0;entryDy=0;`
   - **Vertical (Top to Bottom):**
     `exitX=0.5;exitY=1;exitDx=0;exitDy=0;entryX=0.5;entryY=0;entryDx=0;entryDy=0;`
   - **Vertical (Bottom to Top):**
     `exitX=0.5;exitY=0;exitDx=0;exitDy=0;entryX=0.5;entryY=1;entryDx=0;entryDy=0;`
3. **Always Set Label Background:**
   `labelBackgroundColor=#ffffff;strokeColor=#546E7A;strokeWidth=1.5;fontColor=#263238;fontSize=10;`
   *Crucial: Setting `labelBackgroundColor=#ffffff` prevents edge text from colliding with background lines or borders.*
